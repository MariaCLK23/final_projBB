# Projeto BB — Simulação Acadêmica

Aplicação Flask para uma atividade educativa de conscientização contra phishing.

## Execução

1. Abra esta pasta no VS Code.
2. Ative o ambiente virtual ou crie um novo.
3. `pip install -r requirements.txt`
4. `python run.py`
5. Acesse http://127.0.0.1:5000

O formulário envia POST para `/cadastro` e redireciona diretamente para `/sucesso`.
Não há rodapé na aplicação. Os erros ortográficos exibidos na página inicial são intencionais para a atividade.
